# Linux System Monitor

A Docker-based Linux system monitoring tool that provides real-time information about CPU, memory, disk usage, and running processes.

## Features

- CPU usage monitoring
- Memory usage monitoring
- Disk usage tracking
- Process monitoring
- Docker-based deployment
- Host process visibility support
- Process management support

## Technologies Used

- Python
- psutil
- Docker
- Docker Compose
- Linux
